  crystalkeepsakes/          ← Your local project

  └── .env.production        ← Production config

BUILD COMMANDS
================================================================================

1. PRODUCTION BUILD (for live site):
   npm run build:prod
   
   → Builds to /out/ directory
   → Uses .env.production
   → Upload /out/ contents to /crystalkeepsakes.com/

2. TEST BUILD (for /test subdirectory):
   npm run build:test
   
   → Builds to /out/ directory with /test base path
   → Uses .env.production.test
   → Upload /out/ contents to /crystalkeepsakes.com/test/

3. DEVELOPMENT (local with MAMP):
   npm run dev
   
   → Runs on http://localhost:3000
   → PHP backend at http://localhost:8888/crystalkeepsakes

TROUBLESHOOTING

  → Verify next.config.ts has output: 'export'

  → Test PHP directly: curl https://crystalkeepsakes.com/api/stripe/...

  → Check browser downloads folder
  → Upload manually via FTP

Images don't load:
