# 🚀 SIMPLE FTP PRODUCT UPDATE GUIDE

**Update products on production WITHOUT rebuilding the entire site**

---

## ✅ Quick 3-Step Process

### Step 1: Edit Products in Admin Panel
1. Go to `http://localhost:3000/admin` (dev only)
2. Edit your products (prices, visibility, featured, etc.)
3. Click **"Save Products"** button
4. This generates `/src/data/final-product-list.js`

### Step 2: Copy to Public Folder
Run this command in your project:
```bash
npm run copy-products
```

This copies `final-product-list.js` to `/public/data/` where it can be accessed by both dev and production.

### Step 3: FTP Upload
**File to upload:**
```
/public/data/final-product-list.js
```

**Upload to:**
- **Test site:** `/public_html/test/data/final-product-list.js`
- **Production:** `/public_html/data/final-product-list.js`

**That's it!** No rebuild needed. Changes are live immediately.

## 📊 Admin Panel Features

### Stats Dashboard
The admin panel now shows:
- 👁️ **Visible** - How many products are shown to customers
- 🚫 **Hidden** - How many products are hidden
- ⭐ **Featured** - How many products are featured
- 💰 **On Sale** - How many products have sale pricing
- 📸 **Requires Image** - How many products need customer uploads

### Product List Icons
Each product shows status icons:
- 🚫 **Gray** - Product is hidden
- ⭐ **Yellow star** - Product is featured
- 💰 **Red** - Product is on sale

Hidden products are grayed out in the list for easy identification.

## 💡 Tips

**After uploading via FTP:**
- Clear your browser cache (Ctrl+Shift+R)
- Products update immediately
- No server restart needed

**If products don't update:**
1. Check the file uploaded to correct folder
2. Verify filename is exactly: `final-product-list.js`
3. Check file permissions (should be 644)
