# 📦 Product Update FTP Method - NO FULL REBUILD NEEDED

## The Problem (Before):
- Edit products in admin → Need to rebuild entire site (`npm run build:prod`) → Takes 5+ minutes → Upload hundreds of files via FTP

## The Solution (Now):
- Edit products in admin → Run one command → FTP **one file** → Done in seconds!

---

## 🚀 How It Works

### Step 1: Edit Products in Admin
```
http://localhost:3000/admin
```
- Change prices, visibility, featured status, etc.
- Click "Save Products" button
- Generates: `/src/data/final-product-list.js`

### Step 2: Copy to Public Folder
```bash
npm run copy-products
```

**What this does:**
- Copies `/src/data/final-product-list.js` → `/public/data/final-product-list.js`
- The `/public/data/` folder is accessible via URL: `yoursite.com/data/final-product-list.js`
- Both dev and production load from this location

### Step 3: FTP Upload
**File:** `/public/data/final-product-list.js`  
**Upload to:** `/public_html/data/final-product-list.js`

That's it! No rebuild. Changes are live immediately.

---

## 📋 package.json Explanation

```json
{
  "scripts": {
    "dev": "next dev --turbopack",
    "copy-products": "node scripts/copy-products.js",
    "build:prod": "node scripts/copy-products.js && next build && ...",
  }
}
```

### Key Commands:

**`npm run copy-products`**
- **What**: Copies final-product-list.js to /public/data/
- **When**: After editing products in admin
- **Fast**: Instant (no build)

**`npm run build:prod`** 
- **What**: Full site rebuild (includes `copy-products` automatically)
- **When**: Only for major code changes (new features, layout changes)
- **Slow**: 5+ minutes

## 🔍 Why This Works

### The Magic:
- Your site loads products from `/public/data/final-product-list.js`
- This file is NOT bundled into Next.js chunks
- It's accessed as a static file via public URL
- FTP replaces this one file → instant updates

### Before (Bundled):
```
final-product-list.js → Webpack bundle → chunk-abc123.js
→ Can't replace → Must rebuild
```

### After (Public):
```
final-product-list.js → /public/data/ → yoursite.com/data/final-product-list.js
→ Direct access → FTP replaces → Done!
```

## 💡 Pro Tips

1. **Admin Stats** show your changes before FTP (visible count, featured count, etc.)
2. **Always run** `npm run copy-products` before FTP
3. **Verify file** copied: `ls -lh /app/public/data/final-product-list.js`
4. **Clear browser cache** after FTP: `Ctrl+Shift+R`
5. **Never delete** `/public/uploads/` folder (customer images stored here)

---

## 🚨 Important Notes

**DO NOT edit `/public/data/final-product-list.js` directly!**
- Always edit via admin panel
- Always run `npm run copy-products`
- This ensures `/src/data/` and `/public/data/` stay in sync

**The `/public/uploads/` folder:**
- Stores customer-uploaded images
- Never delete this folder
- Don't include in git (add to .gitignore)
- FTP it once, then leave it alone
