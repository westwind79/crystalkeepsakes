# Auto-Loading Masks System

## 🎯 How It Works

### In Development (localhost)
- Admin panel calls `/api/admin/masks/` API
- API reads `/public/img/masks/` folder in real-time
- Masks automatically appear in dropdown
- **Just drop PNG files and refresh!** ✅

### In Production (GoDaddy)
- Admin panel loads from `/data/available-masks.json`
- Static file with list of all masks
- Automatically falls back if API doesn't work

---

## 📂 Adding New Masks

### For Development (Easy!)
1. Drop PNG file into `/public/img/masks/`
2. Refresh admin panel
3. New mask appears in dropdown ✅

**Example:**
```bash
# Add new mask
cp my-custom-heart.png /app/public/img/masks/

# Refresh admin panel
# → "my custom heart" appears in dropdown!
```

### For Production (GoDaddy)
1. Add PNG files to `/public/img/masks/`
2. Run generation script:
   ```bash
   node scripts/generate-masks-list.js
   ```
3. Upload both files via FTP:
   - The new mask PNG: `/public_html/crystalkeepsakes.com/img/masks/your-mask.png`
   - Updated JSON: `/public_html/crystalkeepsakes.com/data/available-masks.json`

---

## 🔧 Files & Structure

### API Route (Dev Only)
**File:** `/app/src/app/api/admin/masks/route.ts`
- Reads folder dynamically
- Returns JSON list of masks
- Only works in development

### Static JSON (Production Fallback)
**File:** `/app/public/data/available-masks.json`
- Generated by script
- Used in production
- Auto-generated from folder

### Generation Script
**File:** `/app/scripts/generate-masks-list.js`
- Scans `/public/img/masks/`
- Creates JSON file
- Run before building for production

---

## 🚀 Build Process

When building for production:

```bash
# 1. Generate masks list from folder
node scripts/generate-masks-list.js

# 2. Build the site
npm run build:prod

# 3. FTP upload includes:
#    - /data/available-masks.json ✅
#    - /img/masks/*.png ✅
```

## 📋 Mask Naming Convention

**File names are automatically cleaned:**
- `crystal-heart-mask.png` → "crystal heart"
- `3d-crystal-block-wide.png` → "3d crystal block wide.png"
- `dogbone_vertical_mask.png` → "dogbone vertical"

**Best practice:**
- Use lowercase
- Separate words with hyphens `-`
- End with `-mask.png` (optional, will be removed)

## 🆘 Troubleshooting

### "Masks don't load in dev"
- Check dev server is running
- API route should work: `curl http://localhost:3000/api/admin/masks/`
- Check browser console for errors

### "Unexpected token '<'" error
- API returning HTML instead of JSON
- API route not working (static export issue)
- Falls back to static JSON automatically

### "Masks don't load in production"
- Generate JSON: `node scripts/generate-masks-list.js`
- Upload `available-masks.json` to GoDaddy `/data/` folder
- Check file is valid JSON

### "New mask doesn't appear"
- **Dev:** Just refresh browser (API reads folder live)
- **Prod:** Run generation script, upload JSON
